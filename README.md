# studentrosterinC
A program that continuously prompts the user for a student's names and ages until terminated. Upon termination a "student roster" is shown with each student's information.

I developed this program in order to consolidate my understanding of C. The key features focus on dynamically allocating memory via malloc and realloc to cater towards an unknown number of intended students.

Despite focusing on dynamic allocation, the program served immensely towards solidifying my understanding of how data is read, interpreted, and transferred.
